# Монтаж

Веб-конструктор иллюстраций из исходной SVG-библиотеки. Это тестовое задание на позицию Junior AI Developer. Сервис читает заголовок, подбирает подходящие объекты из 20 иллюстраций библиотеки и раскладывает их крупным планом, как в примерах из Figma. Готовую сцену можно отредактировать и скачать как редактируемый SVG.

## Запуск

**Без установки.** Откройте [standalone/Montage.html](standalone/Montage.html) в Chrome или Edge. В одном файле собраны редактор, стили и вся векторная библиотека. Примеры и короткий сценарий проверки собраны в [standalone/Demo.html](standalone/Demo.html).

**Локальный сайт.** Нужен Node.js 22 или новее, пакеты ставить не нужно.

```sh
npm start
```

Откройте [редактор](http://127.0.0.1:8776/) или [демонстрацию](http://127.0.0.1:8776/demo.html). Проект статический: для хостинга достаточно опубликовать папку `dist/`.

## Сценарий проверки (2 минуты)

1. Введите «Удалёнка без выгорания» и нажмите «Собрать композицию». Под кнопкой появится объяснение: какие объекты выбраны и почему.
2. Нажмите «Подключить ИИ», выберите сервис и вставьте ключ. Подойдут OpenRouter, OpenAI, Gemini или любой сервис, совместимый с OpenAI, включая локальные Ollama и LM Studio. Модель сформулирует метафору и выберет объекты только из библиотеки. Без ключа и при ошибке сети работает встроенный словарь, причина показывается в интерфейсе.
3. Откройте вкладку «По объектам» и введите «папка, кошелёк, монета».
4. Поменяйте формат (1200×630, 1080×1080, 800×1200), раскладку и детализацию S/L. Перекрасьте сцену готовой палитрой или загрузите [sample-palette.json](dist/sample-palette.json). Ползунок «Масштаб сцены» увеличивает и уменьшает все объекты вместе.
5. Выберите слой: его можно перетащить, повернуть, продублировать (Ctrl+D), удалить, сдвинуть выше или ниже, сделать главным или фоновым. Есть отмена и повтор (Ctrl+Z, Ctrl+Shift+Z).
6. Скачайте SVG и откройте его в Figma или Illustrator. Каждый объект лежит в отдельной группе с исходными контурами.

Примеры экспорта:

- [«Собрать знания по кусочкам»](examples/knowledge.svg): горизонтальный формат, L, палитра «Ирис», раскладка «Собранно».
- [«Подкасты для долгой дороги»](examples/podcasts.svg): квадрат, L, «Лагуна», «Со смещением».
- [«Навести порядок в бюджете»](examples/budget.svg): вертикальный формат, S, «Персик», «Со смещением».

## Как устроено

```
Figma (Copy as SVG) → source-assets/{S,L}.svg
        │  tools/extract-assets.py: деление листа на объекты, границы, цветовые слоты
        ▼
dist/assets.mjs — каталог: 10 предметов × {S, L} × {главный, фоновый} + 3 фона
        │  tools/build-masks.py: силуэт каждого объекта в сетке 12×12 → dist/masks.mjs
        │
        ├─ dist/semantics.mjs — офлайн-подбор по словарю ассоциаций
        ├─ dist/ai.mjs        — подбор через языковую модель (по желанию)
        ├─ dist/engine.mjs    — раскладка, форматы, палитры, разбор названий
        └─ dist/vector.mjs    — один SVG-рендерер для холста и экспорта
                 ▲
        dist/studio.mjs — интерфейс: сцена, история, слои, настройки ИИ
```

**Хранение и извлечение.** `source-assets/S.svg` и `L.svg` получены из страниц библиотеки Figma через «Copy as SVG». Скрипт `tools/extract-assets.py` делит листы на объекты по пустым промежуткам и считает границы каждого объекта. Библиотека — это 10 главных и 10 фоновых иллюстраций, каждая в размерах S и L. Исходные контуры и порядок отрисовки сохраняются без изменений. Цвета заменяются восемью слотами палитры (`@@0@@`…`@@7@@`), поэтому перекраска не трогает геометрию.

**Переиспользование.** В сцене хранятся только ссылки: ID компонента, роль, позиция, угол и порядок слоя. Плюс один масштаб на всю сцену. Несколько экземпляров ссылаются на один исходный компонент. При смене S/L или роли подставляется другой вариант того же объекта. Последняя сцена сохраняется в браузере.

**Подбор по смыслу.** Работает в два уровня:

- *ИИ.* В `dist/ai.mjs` модель получает список объектов с описанием того, что каждый изображает и какие смыслы несёт. В ответ она возвращает JSON: метафору, два главных объекта и один фоновый с короткой причиной для каждого. Ответ проверяется: неизвестные ID и повторы отбрасываются. Геометрию модель не видит, поэтому дорисовать или изменить объект не может. Ключ хранится только в браузере (в sessionStorage, а с галочкой «запомнить» — в localStorage) и уходит только выбранному сервису. Таймаут 25 секунд, после него включается словарь.
- *Словарь.* `dist/semantics.mjs` содержит основы слов с весами для каждого предмета: «ипотек», «кешбэк», «подкаст», «выгоран» и так далее. Заголовок разбирается на слова, объекты набирают баллы. Если подходит один предмет, второй берётся из естественной пары, например кошелёк и монета или книга и карандаш.

**Раскладка** (`layoutScene` в `dist/engine.mjs`) повторяет правила из Figma:

- пропорции объектов между собой не меняются, у сцены один масштаб;
- самый крупный главный объект задаёт масштаб и стоит в опорной точке раскладки;
- второй объект ставится по изометрической диагонали. Позиция выбирается по оценке, которая считается по **реальным силуэтам** объектов, а не по прямоугольникам вокруг них: насколько силуэт виден в кадре, не наезжает ли на соседа, есть ли между ними зазор, не попадает ли он в зону заголовка;
- если при обычном масштабе объектам тесно, раскладка пробует чуть мельче и берёт лучший вариант;
- фоновый силуэт срезается краем кадра в свободном углу;
- главные объекты рисуются по глубине изометрии: чей силуэт ниже в кадре, тот ближе к зрителю и лежит поверх.

Раскладка «Под заголовок» оставляет пустую зону для текста. В редакторе она обведена пунктиром, в экспорт рамка не попадает.

**Экспорт.** Холст и файл строит одна функция `sceneSVG`. В SVG каждый объект — группа `<g id="object-…" data-component="…" data-role="…">` с исходными контурами и трансформацией. Растровых картинок и скриптов внутри нет.

## Качество подбора

`npm run eval` прогоняет офлайн-словарь по размеченным заголовкам из папки [eval/](eval/). Для каждого заголовка указано, какие объекты подходят по смыслу.

| Набор | Заголовков | Главный объект верен | Было до словаря |
|---|---:|---:|---:|
| dev — по нему настраивался словарь | 40 | 100% | 48% |
| holdout — контрольный, писался вместе с dev | 20 | 100% | 45% |
| **blind — составлен отдельным агентом, словаря не видел** | 30 | **83%** | 40% |

Честная оценка — набор blind: на незнакомых заголовках словарь угадывает главный объект в 83% случаев, а на 3 заголовках из 30 не находит ничего. Для таких случаев и для абстрактных метафор нужен ИИ-режим.

## ИИ-инструменты

- **В продукте:** языковая модель через OpenRouter, OpenAI, Google Gemini или совместимый сервис. Она анализирует метафору заголовка и выбирает объекты из библиотеки.
- **В разработке:**
  - OpenAI Codex — разбор задания, первая версия редактора и извлечения ассетов;
  - Claude Code (Claude) — автораскладка по эталонам из Figma и силуэтам, ИИ-подбор, словарь ассоциаций, тёмная тема и интерфейс, тесты и замеры.
  
  Словарь составлен с помощью LLM и проверен на размеченных заголовках. Слепой набор для проверки составил отдельный агент, которому словарь не показывали.

## Проверки и сборка

```sh
npm test            # 13 автотестов: каталог, подбор, раскладка, ИИ-модуль на подставном сервере, экспорт
npm run eval        # качество словаря на dev / holdout / blind
npm run examples    # пересобрать примеры SVG
npm run standalone  # пересобрать standalone/Montage.html и Demo.html
```

Чтобы заново извлечь каталог из листов Figma, нужен Python с пакетами `fonttools` и `pillow`: `python tools/extract-assets.py`, затем `python tools/build-masks.py`.

## Интерфейс

Тёмная тема по умолчанию, светлая — по кнопке в шапке, выбор запоминается. Подсветка объекта при наведении, анимация появления новой композиции, индикатор ожидания ответа модели, горячие клавиши (кнопка с клавиатурой в шапке или подсказки под холстом). Вёрстка работает от телефона до широкого монитора.

## Ограничения и что дальше

- Словарь знает русские заголовки на бытовые, учебные и финансовые темы. Для остальных тем нужен ИИ-режим.
- Силуэты считаются по сетке 12×12 единиц исходника: для раскладки этого хватает, но тонкие детали (провод лампы) учитываются грубо.
- Следующий шаг для ИИ — дать модели выбирать ещё и раскладку и формат, а качество ИИ-режима проверить на тех же размеченных наборах.

Исходные иллюстрации принадлежат работодателю и входят в тестовое задание. Доступ к репозиторию стоит передавать проверяющему адресно.
