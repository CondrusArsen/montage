# Монтаж

Веб-конструктор иллюстраций из исходной SVG-библиотеки для тестового задания Junior AI Developer. Компоненты можно подбирать по заголовку, перечислять по названиям или добавлять вручную. Сервис собирает сцену, позволяет её отредактировать и выгружает редактируемый SVG.

## Запуск

Для быстрого запуска откройте [standalone/Montage.html](standalone/Montage.html) в Chrome или Edge. В этом файле уже есть редактор, стили и вся векторная библиотека. Для запуска сайта с отдельной страницей демонстрации требуется Node.js 22 или новее. Установка пакетов не требуется.

```sh
npm start
```

Откройте [редактор](http://127.0.0.1:8776/) или [короткую интерактивную демонстрацию](http://127.0.0.1:8776/demo.html). Проект статический. Для хостинга достаточно опубликовать `dist/`.

## Демонстрация для проверяющего

1. Введите «Найти фокус в шуме» и нажмите «Собрать композицию». Подбор связывает фокус и шум с наушниками и рабочей обстановкой.
2. Перейдите в «По объектам» и введите «папка, кошелёк, монета». Конструктор разместит три выбранных объекта на холсте.
3. Переключите формат и S/L. Выберите слой, перетащите его, смените роль, задайте поворот и проверьте порядок слоёв. Отмена и повтор доступны в редакторе.
4. Выберите готовую палитру или импортируйте [sample-palette.json](dist/sample-palette.json). Затем скачайте SVG. В сохранённом файле каждый объект представлен отдельной группой с исходными контурами.

Примеры экспорта:

- [«Собрать знания по кусочкам»](examples/knowledge.svg) — горизонтальный, L, «Ирис».
- [«Найти фокус в шуме»](examples/focus.svg) — квадратный, L, «Лагуна».
- [«Навести порядок в бюджете»](examples/budget.svg) — вертикальный, S, «Персик».

## Как устроено

1. **Хранение и извлечение.** `source-assets/S.svg` и `source-assets/L.svg` получены через Figma «Copy as SVG» со страниц исходной библиотеки. `tools/extract-assets.py` выделяет компоненты по промежуткам между объектами на листах и рассчитывает их границы. В результате десять предметов имеют четыре исходных варианта каждый: S и L, главный и фоновый. Контуры, порядок их отрисовки и фоновые векторные элементы передаются в `dist/assets.mjs`. Выгрузка библиотеки Figma является источником геометрии.
2. **Поиск и компоновка.** По названиям используется каталог с точными именами и синонимами. По заголовку используются тематические признаки, морфологические префиксы и теги предметов. Если подходящих элементов нет, интерфейс предлагает уточнить запрос. Три схемы раскладки задают позиции для широкого, квадратного и вертикального холстов. Один коэффициент масштаба на сцену сохраняет относительные размеры её объектов.
3. **Переиспользование.** Состояние сцены хранит ID компонента, роль, координаты, угол и порядок слоёв. Несколько экземпляров ссылаются на один исходный компонент. При переключении S/L или роли меняется исходный вариант. Последняя сцена сохраняется в браузере.
4. **Палитра и экспорт.** Выгруженные заливки и обводки привязаны к восьми цветовым позициям. Палитра задаёт четыре цвета фона и четыре цвета объектов. Форматы импорта — текстовый список из восьми HEX, JSON-массив или JSON-объект `{"colors":[...]}`. Холст и экспорт используют один SVG-рендерер. В экспорт попадают отдельные группы объектов, параметры трансформации и исходные векторные контуры.

## AI-инструменты

В разработке использован OpenAI Codex для разбора требований, реализации, написания проверок и правок по итогам тестирования. В приложении смысловой подбор локальный и детерминированный. Его качество зависит от русскоязычного словаря и тем библиотеки. Заголовки остаются в браузере, запуск не требует ключей и внешнего API.

## Проверки и воспроизведение

```sh
npm run examples
npm run standalone
npm test
```

Для повторного извлечения каталога из тех же исходных листов Figma нужен Python с пакетом `fonttools`:

```sh
python tools/extract-assets.py
```

Исходные иллюстрации входят в тестовое задание работодателя. Доступ к проекту с этими материалами следует передавать проверяющему адресно.
